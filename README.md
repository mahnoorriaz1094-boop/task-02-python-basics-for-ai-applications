 # Introduction

This task focuses on learning and practicing the fundamental Python concepts required for Artificial Intelligence and Machine Learning development.

Python is one of the most widely used programming languages in AI because of its simplicity, readability, and extensive ecosystem of AI libraries. The purpose of this task is to build a strong foundation in Python programming before moving toward advanced AI concepts.

In this notebook, I practiced variables, data types, loops, dictionaries, functions, and a simple command-line assistant that recommends Core Tech services based on user requirements.
